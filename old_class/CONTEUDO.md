# Old Class - Fundamentos de Python e Analise de Dados

## Visao Geral

Material de disciplina introdutoria cobrindo fundamentos de programacao em Python, estruturas de dados, programacao orientada a objetos, manipulacao de dados com Pandas e introducao a aprendizado de maquina.

## Conteudos Aplicados

### Atividade 1: Fundamentos de Python
- **Arquivo**: `atividade_aberta_1_elmer_rodrigues.py`
- Variaveis e tipos de dados
- Operadores aritmeticos e de comparacao

### Atividade 2: Arrays e NumPy
- **Arquivo**: `atividade_aberta_2_elmer_rodrigues.py`
- Listas e arrays com NumPy
- Operacoes matriciais
- Calculo de medias
- Loops de validacao de entrada

### Atividade 3: Estruturas de Dados
- **Arquivo**: `atividade_aberta_3_elmer_rodrigues.py`
- Tuplas, listas e dicionarios
- Manipulacao de listas (append, insert, delete)
- Operacoes com dicionarios

### Atividade 4: Analise de Dados com Pandas
- **Arquivo**: `atividade_aberta_4_elmer_rodrigues.py`
- Operacoes com DataFrames em dados de e-commerce
- Agregacoes (media, minimo, maximo, value_counts)
- Analise temporal de vendas (vendas por mes)
- Visualizacao com graficos de barras
- Analise de metodos de pagamento

### Atividade 6: Selecao de Features com RFE
- **Arquivo**: `atividade_aberta_6_elmer_rodrigues.py`
- Recursive Feature Elimination (RFE)
- Dataset de severidade de doencas em tomate
- Teste de 1 a 20 features com validacao cruzada
- LinearRegression como estimador base
- Visualizacao dos resultados de selecao

### Aula 3: NumPy e Programacao Orientada a Objetos
- **Arquivos**: `aula_3_elmer_rodrigues copy.py`, `car.py`
- Arrays NumPy
- Classe Car com rastreamento de odometro
- Metodos: `get_descriptive_name()`, `increment_odometer()`, `read_odometer()`

## Bibliotecas Utilizadas

- **NumPy**: Arrays e operacoes numericas
- **Pandas**: Analise de dados tabulares
- **Matplotlib**: Visualizacao de dados
- **scikit-learn**: RFE, LinearRegression, cross_val_score

## Conceitos-Chave

- Fundamentos de Python (variaveis, operadores, estruturas de dados)
- Programacao orientada a objetos
- NumPy para computacao numerica
- Pandas para analise de dados
- Visualizacao basica de dados
- Introducao a selecao de features em ML
